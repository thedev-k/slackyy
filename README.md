Slackyy is a Slack bot which is slacking off. 
It uses NASA's API to pull the picture of the day Also a custom command /slackyy-iss to pull the current coordinates of the iss and also view it on Google Maps.

# Features #
- APOD —— Astronomy picture of the day from NASA 
- ISS Location — Current location of the ISS
- Cat facts — Random cat facts
- Ping — check not for latency
- Help — listing all commands available.

## Quick Start ##
**Prerequisite**
- Node.js 16+ and npm
- Slack workspace with bot token
- NASA API key

# Setup #
- Clone the repository
- create .env
- Run locally (node index.js)
## Commands ##
- /slackyy-apod
- /slackyy-iss
- /slackyy-catfact
- /slackyy-ping
- /slacky-help
